# Campus Event Portal – Supabase setup

1. Supabase Dashboard → SQL Editor → New query → paste `supabase/schema.sql` → Run.
2. Authentication → Sign In / Providers → turn ON "Allow anonymous sign-ins".
3. Open `index.html` (or deploy the folder to Netlify / Vercel / GitHub Pages).

Viewing all registrations (admin): Dashboard → Table Editor → `registrations`.
